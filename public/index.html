Konfigurasi Google OAuth Diperlukan

Aplikasi belum mendeteksi GOOGLE_CLIENT_ID dan GOOGLE_CLIENT_SECRET di file .env Anda.
Silakan buka file .env dan lengkapi kredensial Google Cloud Console Anda agar dashboard dapat terhubung.

GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_client_secret
GOOGLE_REDIRECT_URI=http://localhost:3000/api/auth/callback

Hubungkan ke Google Drive

Klik tombol di bawah untuk masuk dengan akun Google Anda dan memberikan akses pengelolaan Google Drive secara lokal.
